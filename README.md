# Auto Posto Estrela D'Alva

Sistema de promoção e gestão para o Auto Posto Estrela D'Alva.

## Descrição

Site institucional do Auto Posto Estrela D'Alva com sistema de promoção de aniversário de 1 ano, incluindo cadastro de participantes, registro de abastecimentos e sorteios semanais.

## Estrutura do Projeto

- `index.html` - Página inicial
- `promocoes.html` - Página de promoções
- `cadastro.html` - Cadastro de participantes
- `dashboard.html` - Painel do participante
- `admin.php` - Painel administrativo
- `api_*.php` - APIs do sistema

## Tecnologias

- HTML5, CSS3, JavaScript
- PHP 7.4+
- MySQL/MariaDB
- Font Awesome 6.4.0
- SweetAlert2

## Funcionalidades

- Sistema de cadastro de participantes
- Registro de abastecimentos com validação de NFC-e
- Geração automática de códigos da sorte
- Upload de fotos de cupom fiscal (até 50MB)
- Dashboard do participante
- Painel administrativo
- Sistema de autenticação
- Sorteios semanais

## Promoção

Campanha de 1 ano do Auto Posto Estrela D'Alva com sorteios semanais de novembro e dezembro de 2025, culminando no grande sorteio do dia 20/12/2025.
